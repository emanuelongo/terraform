Para que pruebes lo que ya hay:

1. Abre Docker Desktop y comprueba de que esté corriendo.
2. Abre la terminal desde VSCode y ejecute:
   
2.1. terraform init

2.2. terraform apply -auto-approve

3. Con eso ya habrás levantado el contenedor y podrás abrir esta URL para ver la app funcionando:
   
3.1. http://localhost:8080
